- Mechanism (nest_drift.py): the planner sends translation = pivot + R*corner (corner = box min corner) and the client LERPS the
  translation while it SLERPS the rotation. A part's mid-chunk error depends on its corner; tip_1/tip_2 were rooted at y -6.3
  (inside guard_1, corner 0.2 block below the core's -3.0), so their error differed from the core's by up to 0.024 block along
  the face normal, more than the 0.006-0.010 nesting margin. Original rig, worst margin (block, < 0 = pokes through):
    all chunks: tip_1/core z -0.0140, tip_1/edges x -0.0231 z -0.0167, tip_2/core z -0.0146 (k5->6, the 121 deg hit-1 chunk)
    hit 2 (keys 20-35): tip_1/core z -0.0003, tip_1/edges z -0.0035, tip_2/core z -0.0031 (k21->22 = compare t25)
- Fix (rig_parts_s1.py): TIP_ROOT = BLADE_Y[0] (-3.0, where core / edges / rims start): same corner y, so only the tiny
  x/z corner differences remain. After: every tip pair positive on all chunks (tip_1/core z +0.0085, tip_1/edges x +0.0027
  z +0.0055, tip_2/core z +0.0023). Visible geometry is unchanged (only the hidden root moved); corner distance 0.45 block
  (= the core's), held-vs-rig profile check unchanged.
- Residual (not fixed, minor): the deepslate fuller (starts at 1.6, corner 0.29 block above the core's) still sinks INTO the
