- B5-B8 の「yaw -45 (敵へ向く)」は、-45 が術者の右 (カメラ側) への回転で「敵向き」と矛盾 → **修正済** (yaw 0 = 敵向き、顔は正面寄りに見える)。

- 回転方向を読み取れたのは B3 (top CCW 仮、低信頼) と B4 (camera CCW) のみ。B5 のループの向きは [U] のまま (創業者質問ではなく設計メモに回す、下の判断)。

## Check B (事実確認: 動画フレームを先に読んでからシートと突き合わせ)
一致: 接触 3 回 (f811 / f858 / f905-910)、体で振る斬撃なし、V 字に開く形なし、B1 の 1 フレーム立ち、B2/B11 の画面右向き、B5-B6 の C 字・左右の円盤ループ・斜め整列・f858 の集中、B10 の smear と黄色の輪 + X、接触間隔 32 / 31 tick。
不一致と対応 (再観察: f896 f900 f903 f820 f821 f913 を自分で見直した):

- **B3/B4 の切替**: f820 は後ろへ水平、f821 が腰で刃先右下の立ち姿 → 切替は f821 = t16 → **修正済**。
- **B10 のアップ終了**: f913 は既に広角 (術者が敵の右) → B10 を f905-912、B11 を f913 開始に **修正済**。
- **B3 の細線**: 敵の頭上ではなく胴の高さを貫いて右上へ抜ける → **修正済**。
- **B3 の形**: 完全な輪ではなく術者の下半身を巻く下側の弧 (太い端が後ろ、細い端が敵側) → **修正済**。掃引方向が決められないのは変わらず [U]。
- B3「刃は不動」は概ね保持 (f808→811 で腕がやや上がり上体が前へ捻る) → **修正済**。
- B4「f829 で画面上へ消える」は誤り (f830 以降も頭上の三日月の中央に居る) → **修正済**。
- B8 で手元の鋏と敵側の連結ハサミが同時に 2 本 → 明記した。
- 音の tick: f808 (7.4) の境界 → t=8 のまま「f808-809」と表記。
- 軽微 (据え置き): B0 f771 の術者は半透明の残像 (実体は f780 頃から)。
