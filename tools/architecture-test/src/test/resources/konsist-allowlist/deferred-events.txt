# ADR-0134 deferred-events allowlist (publisher-side)
#
# DomainEvent FQNs listed here are exempt from the "publisher must exist"
# check. Use only when the publisher is intentionally deferred to a later
# wave (Wave 6 Paper adapter / Phase 2+ feature) or when the event is
# confirmed dead and pending removal.
#
# Format: 1 FQN per line. Blank lines and lines beginning with `#` are
# ignored. Each section header documents the deferral category so future
# authors can verify each entry is still legitimate.
#
# Annual hygiene: review every entry once per release cycle and remove
# entries whose deferral is no longer load-bearing. A line removed from
# this file is a positive event — it means the publisher shipped.
