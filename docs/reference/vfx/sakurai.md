## 2. ファミ通 モーション特別編 (本文確認済み) [一次]

https://www.famitsu.com/news/201904/22174831.html

- 構えは原作より深く引く。3D は補間で「もっさり」するので 2D より誇張する。助言は「ちょっと大げさに引く！ 一気に動かす！」。
- 溜めに長く時間を割き、ギリギリまで保持してから一気に切り替える。中割りは 1 フレームだけ。
- 同じ絵の順でも時間配分を変えると印象が変わる。見せたい部分に時間を割く。
- フォロースルーを攻撃までより長く取る場合がある。戻りの軌跡は変える。
- 動きに攻撃が負けて印象が弱いときは、その都度手直しして攻撃を際立たせる。

**Astera への含意:** Display の補間は、溜めでは 0 (保持)、発生で 1t のスナップ、余韻は長い補間。補間の滑らかさを均一にしない
(=`swing` の keyframe 区間ごとに ease を変える)。

## 3. ヒットストップ (ファミ通コラム vol.490 の翻訳記事) [二次]

https://sourcegaming.info/2015/11/11/thoughts-on-hitstop-sakurais-famitsu-column-vol-490-1/

- 攻撃側と被弾側の停止時間は同じ。強い攻撃ほど長い。攻撃ごとに補正値を持つ。飛び道具は短い。停止時間に上限を設ける。
- 振動は大きく始まり、停止中に縮む (事前計算)。被弾の振動は地上は左右・空中は上下。カメラが遠いほど振動を強く。
- 停止中に攻撃側がごくゆっくり動く (スロー感)。被弾モーションへの切り替えを 4F かけて馴染ませる。
- 多人数戦では短め (止まった相手を第三者が殴れる) — 正本 §0.5 に既出。

**Astera の現状:** `hit_stop` は対象を固定する (術者は `include_caster`)。停止中の揺れの縮み・術者のスロー・被弾モーションの馴染ませは**未対応**。
`camera_shake` は単発の視点ブレで、減衰する揺れではない ([`minecraft-techniques.md`](minecraft-techniques.md) の T-20、[`failure-patterns.md`](failure-patterns.md) の M-19)。

## 4. 規則に追加できる要点 (要約)

1. ヒットストップは強さの階層を作る (軽 1-2t / 重 3-4t / 決め技 6t 目安 [二次])。全攻撃で同じ長さにしない。
2. 重要な瞬間 (撃破・被弾・フィニッシャー) の直前に一瞬止める。
3. 溜めは長く保持 → 発生は 1t のスナップ → フォロースルーは行きより長く別軌道。
4. 白黒で見て読めること。効果音は重要度で決める。
5. 画面振動・フラッシュは「やり過ぎ注意」。強度を設定可能に。
