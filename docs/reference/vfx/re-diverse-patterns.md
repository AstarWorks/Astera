# Re:DIVERSE (社内参考サーバー) から抽出した一般原理

> **Re:DIVERSE の Skript・素材は参考のみ。コード・演出・素材の転用/模倣は禁止 (ライセンス)。原理を抽象化して Astera 独自に設計する。**

[README](README.md) / 参考サーバーを読み取り専用で調べた結果 (2026-10-23) から、**一般化できる原理だけ**を自分の言葉で書いた。
コード・ファイル名・サーバー情報・1 つの技の tick 単位の再現手順は載せない。事例は原理の例示に限る。
タグ [社内参考] = 参考サーバーでの観測。Astera の対応状況は 2026-10-23 のコード照合。

## 0. 観測の規模感 (一般情報のみ)

- 数百本規模のスキルが、粒子・Display・音の組み合わせで作られている。音の指定は粒子と並んで最も多く使われる要素だった。
- 観測されなかったもの: ヒットストップ、カメラ揺れ、FOV 操作、title 演出 (title は失敗通知のみ)。Astera が既に持つ手段の方が多い領域がある。
- 独自のリソースパック (item model・フォントグリフ・ツールチップ枠) に依存する。Astera は ADR-0239 の sprite で同種の手段を自前で持つ。

## 1. 原理カード (14)

各カード: 原理 / なぜ効く / Astera の対応。番号は他ファイルから参照される。

### 技法 1: スプライト Display を粒子の代わりに使う (最優先)
- 原理: 数フレームの絵を、1 つのテキスト Display のグリフ差し替え (2t 刻み) で再生する。明度を固定し、色は後から染め、裏面用に反転した 1 枚を重ねて指向性を持たせる。
  急峻な立ち上がり + 短い減衰の flash、回転しながら飛ぶ火花、opacity の段階減衰など、粒子では出せない「絵」の質感を 1 エンティティで出せる。
- なぜ効く: ブロック粒の解像度を超える。数百粒を毎 tick 出すよりパケットが軽いことが多い [社内参考]。
- Astera: **対応** (ADR-0239 `type: sprite`、`frame_ticks`、`color`)。

### 技法 2: 予兆 (telegraph) = 実寸の外形 + 時間とともに満ちる塗り
- 原理: 範囲の外縁は即座に実寸で出し、内側の塗りを着弾までかけて外縁へ広げる。見る側は「どこに」「いつ」を 1 つの図形で読める。味方/敵で色を分ける。
  詠唱そのものを描画で見せる (陣を少しずつ描く) のも同系統。
- なぜ効く: 範囲と時間が同じ図形に載る。PvP の公平性にも効く。判定半径 = 見た目半径 (D-A5)。
- Astera: **部分**。リング 2 枚で書ける (雛形: `bastion-s3-telegraph`)。専用要素・チーム色は **未対応**。

### 技法 3: クライアント補間に任せる
- 原理: 毎 tick 更新せず、補間時間を長く取って終点を 1 回だけ設定する。軽く、滑らか。向きの予告のように「ゆっくり向きを合わせる」演出に向く。
- Astera: **対応** (T-1, T-2)。

### 技法 4: 音の層とピッチの弧
1. 同じ音を高低 2 ピッチで同時に鳴らすと厚みが出る。
2. チャージは時間とともにピッチ上昇、スイングや減衰は下降。
3. 頂点で一瞬の無音を作ってから一撃を鳴らす。溜め音を止めて着地音を際立たせる。
4. 低音を土台に、高音をトップに重ねる。照準中は 2 音を交互に鳴らして緊張を保つ。
5. 音階を使うと和音・アルペジオが組める (半音 = 2 の 1/12 乗)。pitch の有効域は約 0.5-2.0。
6. 音だけの盛り上げ (上昇 → 突然の停止 → 一撃) は強い。ただし全員に大音量で聞かせない (D-A3)。
- Astera: **部分** (T-32〜T-36)。`play_sound` を `delay_ticks` で並べれば書ける。弧の宣言構文・`stopsound` 相当は **未対応**。

### 技法 5: ビーム = 交差する細い板 + 発射前の「すぼめ」
- 原理: 細長い板を十字に 4-6 枚交差させると、どの角度からでも線に見える。外縁 (濃色) と芯 (淡色) の 2 本構成にし、太さは後から動かせるようにする。
  発射前に一度細くしてから開く (ease の in-back)、終端でもう一度収束させると反動が出る。
- Astera: **部分** (T-7)。`line` formation + quad で近い構成は可能。

### 技法 6: 接線方向の粒子で渦・衝撃波
- 原理: 粒子の初速を位置の接線方向に向けると、輪が渦になる。輪を何重にも出し、輪ごとに位相をずらし半径を広げる。
  判定は輪ごとに 1 回、対象の重複を除いて取る。
- Astera: **部分** (T-18)。quad 粒子の `direction: tangent` あり。

### 技法 7: 螺旋の包絡 + 確率ディテール
- 原理: 螺旋の半径を、中央が太く上下が細くなる周期関数で変える。主材料の粒に、数% の確率で別種のディテール (切れ目を示す斬撃粒など) を混ぜると繰り返し感が消える。
- Astera: formation の `spiral` / `helix` と quad 粒子で近い形は出せる。包絡の指定は **未確認**。

### 技法 8: 巨大な実体を振る
- 原理: 大きな Display を回転の積で扇状に振り、粒子は補助に回す。ピボット = 平行移動、スイング = 一方の回転、モデルの向き補正 = もう一方の回転に役割を分ける。
  削除は最後の更新の次の tick に行う (残骸防止)。
- Astera: **対応** (rig、正本 §7)。

### 技法 9: 予備動作 → 前進
- 原理: 引く動き (ease の in-back) を先に見せてから前進する。判定は前進の途中の 1 回に置く。近接技に広く使える。
- Astera: **部分** (`dash_strike` + rig の ease)。`windup` 構文は **未対応**。

### 技法 10: 発動失敗は資源を返し、すぐ知らせる
- 原理: 設置不可などで失敗したら、コストとクールタイムを返却して通知する。
- Astera: 失敗時の資源返却の有無は **未確認** (`ego_cost` 不足は cast 拒否 + action bar [実コード])。

### 技法 11: 命中は 1 回だけ。命中リストを次段へ持ち越す
- 原理: 1 回の技で同じ対象に二度当てない。1 段目で当てた対象の記録を 2 段目に引き継ぎ、別演出や強化を与える。
- Astera: **部分** (`dash_strike.hit_once`、`has_status`、`cast_skill`)。

### 技法 12: 距離に応じてノード数を変える雷
- 原理: ジグザグ線のノード数を距離に比例させ、線に直交する乱数でずらす。芯と色の 2 重にする。
- Astera: **対応** (`lightning` formation。距離スケールは **未確認**)。

### 技法 13: 収束 = 溜め、拡散 = 解放
- 原理: 粒の広がりを小さくしていく、または中心へ流す (trail) と溜めに見える。解放では逆に広げる。対で使う。
- Astera: **対応** (`Particle.Trail`)。

### 技法 14: 自分(味方)にだけ見える発光
- 原理: 発光を関係者のパケットだけで出し、全員に影響させない。
- Astera: **未対応** (T-4 参照)。

## 2. 観測から得た設計上の教訓 (短いケースノート)

事例は原理の例示。再現手順ではない。

- 魔法陣を粒子で描く詠唱は「描画 = 詠唱の進捗」で効くが、粒子数が膨らむ (D-A1, D-A2)。板 1 枚のフェードインで代替する。
- 長い詠唱は「ピッチ上昇 + 膨張」で時間を持たせる。ただし詠唱中の粒子を毎 tick 出し続けない。
- 低音を 3 層重ねた溜め + 心拍のような周期音は、緊張を作る。
- 巨大物を落として刺す動きは、開始が速く終端で減速する ease が「刺さる」感覚を作る。保持中に時計のような周期音を鳴らし、満タンで合図音を出す。
- 範囲予告 + 落下物は、見えているマーカーの上に本当に落ちる因果の明快さが効く (Gungnir 型: マーカー → 落下する槍 → 大きな衝撃)。
- 伸びる柱で腕を表現し、見た目と判定を一致させる。音を 3 つ同時にピッチ上昇させる。
- 溜め中は被ダメ軽減にする (「溜めると強い」と「溜め中は硬い」の両立)。固定時間は 20t 以内 (D-A8)。
- 1 段目はノックバック無し、受付時間内の再入力で 2 段目の追撃 (命中記録を持ち越す)。

## 3. レアリティ別の表現ラダー

**格 = 演出の 4 軸 (スケール・層・時間・音) を段階的に上げ、コスト (MANA / CT 相当) と必ず連動させる。**

### 3.1 参考サーバーのレアリティ定義 (一般情報)

- 5 段階 (Common / Rare / Epic / Legendary / Mythic。Mythic は武器に未使用)。表示は星の数 + 色 + 太字。ツールチップ枠もレアリティごとに変わる (パック側)。
- 名前の見た目だけで格が分かる: Legendary は 1 文字ごとのグラデ + 太字イタリック、Common は単色。
- 入手確率は上位ほど極端に低い (Rare 2% → Epic 0.0007% → Legendary 0.0002%、いずれも天井あり)。武器数は Common 128 / Rare 62 / Epic 9 / Legendary 5。
- **コストの階段** (平均): MANA Common 52 → Rare 63 → Epic 164 → Legendary 250。CT 8s → 10s → 39s → 63s。
  Rare までは日常技、Epic から必殺技という断層がある。Epic / Legendary は MANA 3-5 倍・CT 5-8 倍で、演出尺が伸びる代償を払う。

### 3.2 階層表

| 階層 | スケール | 層 (同時に重ねる要素) | 持続 | 音 | 必須ギミック | コスト倍率 (観測) |
|---|---|---|---|---|---|---|
| Common | ≤ 3 ブロック | 1 (粒子のみ) | ≤ 1s | 1 音 (命中音) | なし | ×1 |
| Rare | ≤ 6 | 2 (粒子 + 小 Display / sprite) | 1-3s | 2 音 (1 層 + ピッチ弧) | 予備動作 or 着弾 sprite | ×1.2 |
| Epic | ≤ 12、Display scale 2-5 | 3-4 (Display + sprite + 粒子 + telegraph) | 4-10s | 3-5 音 (2 ピッチ同時 + 上昇/下降弧 + 無音 → 一撃) | **telegraph 必須**、溜め → 解放 → 余韻の 3 段、色 2-3 | ×3 |
| Legendary | 12-20、Display scale 5-10 | 5+ (陣の表裏 + 柱 + 巨大 Display + sprite + telegraph + 環境音) | 10-30s、**フェーズ 3 段で強化** | 専用の音セット (固有モチーフ) + 低音 + 最終一撃前の無音 | 色相遷移、固有メカニクス、入手・装備・キルのいずれかに専用演出 | ×5 |
| Mythic | 画面全体 | + カメラ / HUD 連動 | — | — | 前例なし。Astera では title / action bar / boss bar との連動の余地 | — |

軸別の差 (Common → Legendary): 尺は約 1 秒から 10-30 秒へ。音の回数は 2 回から 14-16 回へ(上位は低音を混ぜる)。主役は vanilla 粒子から、巨大 Display + 大きな sprite + 陣 + 光柱へ。
範囲は 3 ブロックから半径 11-20 へ。色は単色から「時間で色相が遷移」へ。準備は無しから必ず可視の予告へ。

「格」の作り方 (要約): ①スケール階段 ②レイヤ数 ③溜めを見せる時間 ④時間経過で色・密度・ピッチが上がり続ける ⑤その技だけの音の組み合わせ ⑥固有の仕掛け (運で段階が変わる、状態を消費してボーナス、構えの切替、ヒット数で強化、チャージ中断のペナルティ) ⑦入手時の演出 ⑧idle / kill 演出はスキル本体以外ほぼ無い (差別化の余地)。

### 3.3 事例ノート (原理の例示)

| 例 | 学ぶ原理 |
|---|---|
| Seventh Cannon 型 (Legendary) | 抽選で段階が決まり、**数・色・音階が 1 段ごとに積み上がる加算演出**。間隔を広げて「引き」を効かせ、最後に一点へ収束してから着弾 |
| Glacial Storm 型 (Legendary) | 発動 → 着弾 → 持続 3 段階 → 終端爆発の起承転結。**フェーズごとに粒の密度・色の濃さ・音の高さが上がる** |
| Gungnir 型 (Legendary) | マーカー → 落下する巨大物 → 大きな衝撃。**スケール階段**と、見えているマーカーの上に落ちる因果の明快さ。粒子数を盛りすぎると危険 |
| Aurora Heal 型 (Legendary 回復) | 空全体が変わる演出で格を出す。**威力が小さく演出だけ大きい = 見た目と効果の乖離**がアンチパターン |
| Houryuutou 型 (Epic) | 構えの状態機械 (抜刀/納刀) と、ヒット数による段階強化。idle 演出を持つ数少ない例 |
| Dimensio Mortis 型 (Epic) | 状態を消費してボーナス。出発側と到着側に正逆の sprite を対で出し「穴が空いて閉じる」を表現。軽いコストでも格が出る |

### 3.4 階層のアンチパターン (Epic / Legendary)

1. 粒子の暴力 (1 tick に数百〜数千粒) は低スペックで落ちる。Display の巨大化で代替する。
2. 完全固定 70-100t はテンポを損ねる。固定中の無敵・軽減とセットにする。
3. 入手演出の整備が最上位だけ抜ける。格の最上位が入手時に確認できない。
4. 威力が小さいのに演出だけ大きい (見た目と効果の乖離)。回復系は範囲 = 見た目ではなく「味方に見える光」に絞る。
5. 階層を飛ばして下位に長尺を入れると格が崩れる [推論]。

### 3.5 Astera への対応づけ

- **Astera にも `Rarity` はある** (`plugin/core/.../domain/item/Rarity.kt`: `COMMON, UNCOMMON, RARE, EPIC, LEGENDARY`、MYTHIC 無し。ADR-0073)。
  視覚処理は下流の renderer / loot table に任されており、**skill 演出の格は規定していない**。
- 人格武器は、`bastion-greatsword` (`rarity: rare`) を除く 9 本 (edict-blade / orrery-staff / couture-rapier / crimson-chain-axe / ember-gauntlet / gossamer-katana / verdict-hammer / vendetta-rifle / sigil-rifle) が `rarity: epic`。
  **同じ武器の s1 〜 ego の格の差は rarity では出ない**。ADR-0230 に rarity による演出規定は無い。
- そこで **「技の格 = 重要度 (importance 1-10、正本のチェックリスト 1)」** をラダーの軸にする(提案。未合意):

| 技の格 (importance) | 想定スロット | 階層 | 備考 |
|---|---|---|---|
| 1-3 | 通常攻撃・小技 | Common 相当 | 1 層・≤ 1s・1 音 |
| 4-5 | s1 | Rare 相当 | 2 層・予備動作か着弾 sprite |
| 6-7 | s2 / s3 | Epic 相当 | telegraph 必須・溜め → 解放 → 余韻・音 3-5 |
| 8-9 | s3 の大技・コンボ終端 | Epic 上位 | 巨大 Display 1 つ + フェーズ変化 |
| 10 | E.G.O (`ego_cost: 100`、`trigger: drop`) | Legendary 相当 | 3 フェーズ・専用音・色相遷移。コストは E.G.O ゲージ |

- コスト倍率は Astera ではエネルギー/弾薬 (`resource_cost`)・`cooldown_ticks`・`ego_cost` に当たる。「演出が長い = 隙も長い」。参考サーバーの倍率はバランス値としてそのまま使わない。
- 現状の穴と適用は [`next-improvements.md`](next-improvements.md) を参照。
