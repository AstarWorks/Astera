## 原則 (Principles)

1. **カスタム絵は「黒背景で単体でも成立する」ドット絵セットから。** 小さな固定スプライト群 (十字の煌めき、点、細線、柔らかい煙の塊) を作り、その組み合わせだけで全演出を組む。[観察]
2. **同じ部品を極端なスケール差で使う。** 同一スプライトが豆粒から画面一杯まで出る。大小の落差が迫力の主因で、部品の種類を増やすより効く。[観察]
3. **柔らかい煙の塊が「画面を覆う幕」になる。** ピクセル縁の丸い煙を手前に大きく出し、その奥で線や星が走る。[観察]
4. **軌跡は実線でなく点線・細い弧で描く。** ダッシュ・テレポート・斬撃の経路は、間隔の空いた小点の列か細い弧で示す。[観察]
5. **配色は 2 色の層で作る。** 主色 (桃・緑・赤橙) に対し、白や青を差し色に重ねる。黒い煙は火の色と混ぜて濃淡を作る。[観察]
6. **段階終了: 爆発のあとに細かい粒を残す。** 中心の破裂 → 放射線 → 微細な粒が漂う、の 3 拍。余韻の粒は爆発より小さく疎に。[観察]
7. **形は球殻・ドーム・輪の幾何で組む。** 地面の輪 + 球状に広がる煌めき十字、プレイヤー周囲を回る点線リング。[観察]
8. **ファーストパーソンで武器が視界に入る構図を前提にする。** 近接の大きな炎の四角や床一面の花びらは、カメラ近傍で読まれる前提の大きさで置く。[観察]

## 技法 (E3-n)

Astera 対応: 対応 / 部分 / 未対応 / 未確認。出典は `https://x.com/s10129/status/<id>`。

### E3-1 ドット絵スプライトセット (黒背景で判定)
- 見た目: 煌めき十字・点・細線・煙塊を並べた一枚絵で、黒背景でも輪郭が潰れない。
- 効く理由: 部品が単体で完結するので、加算的に重ねても濁らない。
- 作り方 [推論]: 自作テクスチャをリソースパックに載せ、パーティクル or TextDisplay のグリフとして使う。
- Astera: 対応 (`type: sprite` / ADR-0239 の TextDisplay グリフ、`frame_ticks`)。ただし 1 グリフ最大 256px。
- 出典: https://x.com/s10129/status/1815727325864210681

### E3-2 極端なスケール対比
- 見た目: 同じスプライトが小粒と画面を埋める大きさで同時に出る。
- 作り方 [推論]: Display の scale を数十倍に振る。近接カメラ前に大きく置く。
- Astera: 部分 (sprite の scale / `size_over_life` は可。ただし画面占有サイズでの実測が無く、バジェット <= 60 display/cast を食う)。
- 出典: https://x.com/s10129/status/1816274522368270618 , https://x.com/s10129/status/1765020618771378491

### E3-3 ピクセル縁の柔らかい煙塊 (画面カバー)
- 見た目: 丸く柔らかいが縁は段差のある煙が手前に広がる。
- 作り方 [推論]: アルファ付きスプライトを数枚、緩く拡大しながらフェード。
- Astera: 部分 (sprite + `size_over_life`/`alpha_over_life`。画面全体は `screen_flash` が近い役割だが形は持てない)。
- 出典: https://x.com/s10129/status/1815618638034190793 , https://x.com/s10129/status/1816274522368270618 , https://x.com/s10129/status/1811552228756410557

### E3-4 放射状の点・線の星形 (starburst)
- 見た目: 中心から点列と細線が放射し、先端が伸びて消える。
- 作り方 [推論]: 角度を等分し、各線を点列 or 細長い sprite にして外へ移動。`count=0` の方向付きパーティクルでも近似可。
- Astera: 部分 (`emit` + `velocity {direction, speed, spread_degrees}`、`formation` で放射配置。細線 sprite は自作要)。
- 出典: https://x.com/s10129/status/1815618638034190793 , https://x.com/s10129/status/1811552228756410557

### E3-5 点線・細弧の軌跡 (ダッシュ / テレポート / 斬撃)
- 見た目: 経路に沿って間隔を空けた小点が並び、弧や直線を描く。
- 作り方 [推論]: 経路を等間隔サンプルして 1 点ずつ 1〜2 tick ずらして出す。軌跡は固定位置に残し、本体だけが動く。
- Astera: 部分 (`trail` パーティクル、`shape` の arc/line、rig_path でのサンプリング。docs/contributing/vfx-team/particles.md の `trail` は近接で四角に見える注意あり)。
- 出典: https://x.com/s10129/status/1812677029311271277 , https://x.com/s10129/status/1813730063722135865

### E3-6 命中時の白い斬撃ファン
- 見た目: 命中点から白い細斬撃が扇状に数本。
- 作り方 [推論]: 細長い白スプライトを角度違いで同 tick に出し、短時間でスケールアウト。
- Astera: 対応 (sprite + `formation` 扇配置、`hit_stop` との併用)。
- 出典: https://x.com/s10129/status/1813730063722135865 , https://x.com/s10129/status/1809793994689294401

### E3-7 2 色レイヤー (主色 + 差し色)
- 見た目: 桃 + 青、緑 + 白など、2 色の層がずれて重なる。
- 作り方 [推論]: 同じ形を色違いで 1〜2 tick・数 % ずらして重ねる。
- Astera: 対応 (`color_over_life`、sprite 色指定、`dust_color_transition` は近接で四角化するので遠景限定)。
- 出典: https://x.com/s10129/status/1813730063722135865 , https://x.com/s10129/status/1793870648416334183

### E3-8 球殻ドーム + 地面リング
- 見た目: 煌めき十字が球面状に広がり、足元に輪が走る。
- 作り方 [推論]: 球面サンプル点に sprite を置いて外向き移動、リングは別要素。
- Astera: 対応 (`shape: sphere/circle`、`formation`)。
- 出典: https://x.com/s10129/status/1793870648416334183 , https://x.com/s10129/status/1780893206206632002

### E3-9 黒ピクセル煙 + 赤橙の火
- 見た目: 黒い粒状の煙と赤・橙の炎が混ざって立ち上る。
- 効く理由: 明暗の対比で火が沈まない (既存原則「Dark + bright」と同じ)。
- Astera: 対応 (smoke 系チャンネル `cloud` 再テクスチャ + ember チャンネル、ADR-0274)。
- 出典: https://x.com/s10129/status/1784063889623355774

### E3-10 近接の大きな炎の四角 + 火の粉の柱
- 見た目: カメラ近くに大きな炎の四角面が立ち、粒の柱が昇る。
- 作り方 [推論]: block/quad Display を発光で大きく置き、細粒を上向き放出。
- Astera: 対応 (`kind: block` の炎要素は `content/vfx/ember-*.yaml` に例あり、`brightness: 15`)。
- 出典: https://x.com/s10129/status/1775009621805269326

### E3-11 花びら・粒のカーペット
- 見た目: 床や空間一面に粒や花びらが敷かれ、命中で舞い上がる。
- 作り方 [推論]: 領域サンプル + 低速、長めの寿命。
- Astera: 部分 (`emit` は可。数が多く、display バジェットのため vanilla/チャンネルパーティクルが現実的)。
- 出典: https://x.com/s10129/status/1809793994689294401 , https://x.com/s10129/status/1813730063722135865

### E3-12 爆発 → 余韻の細粒 (3 拍構成)
- 見た目: 中心破裂、放射線、そして微細粒が漂って消える。
- Astera: 対応 (`start_tick`/`end_tick` で拍を分けられる。余韻は寿命の長い粒を別要素で)。
- 出典: https://x.com/s10129/status/1815618638034190793 , https://x.com/s10129/status/1811552228756410557

### E3-13 プレイヤー周囲の公転点線リング
- 見た目: 点線の輪がプレイヤーの周りを回る。
- 作り方 [推論]: `follow` 付きの circle 配置に回転キーフレーム。
- Astera: 対応 (`follow: true`、rotate キーフレーム、`shape: circle`)。
- 出典: https://x.com/s10129/status/1780893206206632002 , https://x.com/s10129/status/1788809119870411138

## Astera とのギャップ (gaps)

1. **自作ドット絵セットの揃い。** 煌めき十字・点列・細線・柔らかい煙塊を黒背景判定で揃えた共通セットが `content/sprites` に無い (未確認、あれば要比較)。E3-1/3/4。
2. **画面占有スケールの実測。** 数十倍スケールの sprite がカメラ近傍でどう見えるか未検証。バジェット (<= 60 display/cast) との折り合いも未確認。E3-2/3。
3. **細線 sprite と点線生成の標準部品。** 経路サンプル → 点列を出す YAML の定石が無い (rig_path 頼みで手作業)。E3-4/5。
4. **多数粒 (カーペット / 微細粒) の置き場。** Display では数が足りず、チャンネルパーティクル (ADR-0274) の ember/spark/smoke でどこまで担えるか未評価。E3-11/12。
5. **煙塊の画面カバー。** `screen_flash` は全面色のみで、形のある煙幕を画面に被せる手段が無い。E3-3。
