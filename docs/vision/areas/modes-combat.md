# Area: modes, combat, weapons

Owner track `wp/modes-combat`. Seed: audit 2026-10-26. Items: Board prefix `MODE-`.

## 構想 (source)
- Siege PvP with gun / sword / magic roles, 15-30 min matches (`docs/game-design/vision.md`, `pillars.md`).
- **Norma is part of every mode** (founder 2026-10-26, ADR-0268: shared layer `content/norma-layer/layer.yaml`, the old `norma` mode is now `skirmish`): stars pop from generators, a kill bursts carried stars, per-level STAR or KILL goal, 100% Orange Juice style; Norma levels unlock weapon rarities (ADR-0292), never end a match (ADR-0288, ADR-0271, `docs/game-design/stars-and-norma.md`).
- Weapons RTM-style MAIN+SUB caps; the 2-weapon cap is kept; starter kit includes a gun.
- Matches target siege-scale maps; keep a small debug arena for e2e.
- Playable loop: queue, form, countdown, ACTIVE, fight, respawn, objective, end summary + rewards, lobby (`docs/game-design/playable-loop-checklist.md`).

Left-click on a cover block with a tool calls `HitCustomBlockUseCase` (6-tick cooldown): the right tool does 100 per swing, the wrong one 25 or nothing, a vanilla dig on cover is cancelled; crack stages go out via `IBlockBreakAnimationGateway` (`sendBlockDamage`) and per-tool break sounds play. Cover blocks `reinforced-wall` (stone 400 HP, pickaxe), `barricade` (wood 300, axe), `sandbags` (soil 200, shovel), `hardened-soil` (500, pickaxe) are placed in all siege-isles variants via `content/structures/cover-*.yaml`; visual-backed definitions are recognised by their full reserved block state (ADR-0300); legacy structure material cells need explicit state migration. - Cover skill opt-in (ADR-0280, superseded HP lifecycle by ADR-0297): guns/spells with `block_damage` chip cover through `CoverBlockService` (pistol 12, rifle 20, shotgun 30, flame-burst 35, frost-nova 20, lightning-bolt 25, frost-shard 10); absent opt-in means no block damage. `block_place` and `place_shape` make temporary cover. These chips and left-click tool swings add to the same store as area tools, and all surviving damage expires after the shared idle window. Broken geometry returns at arena repair; expired damage never recreates blocks.
- Combat: resource pools, melee, mob damage, 15 statuses, element matrix.
- Annihilation pillars are mining blocks (MODE-A1/A2): tier 1 hard wood / axe (`stripped_dark_oak_wood`), tier 2 hard dirt / shovel (`coarse_dirt`), tier 3 hard stone / pickaxe (`polished_deepslate`); each `StagePillar` declares `block` + `affinity`. Hand break and `break_area` tool skills (via `PaperSkillWorldGateway`) damage the pillar; a skill of the pillar's affinity counts x3, another tool x1, a hand break with the matching tool x2, a weapon hit x0.18, all scaled linearly to 0 between 8 and 32 blocks (`PillarDamageRules`, tunables `pillar_*` in `content/game-modes/annihilation.yaml`). HP 3200 / 4800 / 6000: one player with the matching tool skill + hand break fells tier 1 in ~37 s, weapons alone ~150 s. The pillar block never breaks; e2e tune restores flat damage (`docker/e2e-tune-content.sh`). Game-sim `AnnihilationPillarScenarioTest`; feel/pacing is founder-check.
- Mid ore (track mid-norma): each stage's Mid is a dense Annihilation-style mine (`content/ore-nodes/<stage>.yaml`: siege-isles family 92 nodes, annihilation-arena 74, temple-trouble 42; was 10 each) with emerald at the very centre, then diamond, gold-tier, iron-tier on the rim. A node is a custom block with HP (`base_durability` 800 iron/ironwood/clay, 1200 gold, 1400 heartwood/silt, 2000 diamond, 2400 emerald) and per-tool-class `tool_effectiveness`: pickaxe ores (iron/gold/diamond/emerald), axe ores (`ore_timber_node`, `ore_heartwood_node`) and shovel ores (`ore_clay_node`, `ore_silt_node`); the matching tool deals 100-250 a hit, the other classes 12-25. Each node group has `min_norma_level` (iron/wood/clay 1, gold-tier 2, diamond 3, emerald 4): below it no damage, villager-no sound and action bar `ore.needs-level`. `level_speed` (1.0/1.15/1.3/1.5/1.75 by Norma level) and `skill_mult` (3.0, same as the pillar tool-skill match mult) live per ore-nodes file; bad YAML (missing level 1, unknown tool/tier, non-positive numbers) fails loudly. `break_area` tool skills strike a node through the core port `IOreNodeStrikes` (same affinity/level rules, drops, regrowth; never reports BROKEN to the ledger). Game-sim `MidOreNodeScenarioTest`, `OreNodeToolSkillScenarioTest`; `MatchArsenalE2eTest` still names the old node cells and needs updating by bots-qa; pacing is founder-check.
- Stage allocation (MODE-06): a stage id is one fixed set of coordinates in the `arenas` world and hosts one match at a time (`MatchFoundUseCase.isStageBusy`). World slots / `ArenaPaster` (ADR-0255) are design only, with no code yet, so instancing does not exist. Each siege-family lane therefore has its own copy of the stage: `siege-isles` (break-core) and `siege-isles-{tnt,wool,jewelry,loyal,mini-tnt}`, each shifted +800 on z (stages 800 apart, the ADR-0255 region-independence distance), with their own star generators `siege-<variant>-{north,south,center-east,center-west}`. The six siege lanes now run concurrently. When ADR-0255 slots land, delete the variants and point the lanes back at `siege-isles`. Costs: six large stages to build at boot and in the arena marker; keep the copies in sync when editing `siege-isles.yaml`.

## 理想形
Play shows Norma-based modes and PvE first; siege variants sit in an "advanced" group until each has a real-server playthrough. Every mode carries the Norma layer. A newcomer gets gun, sword and staff access in the first match within the 2-weapon cap, and the sidebar always shows the goal ("Lv n/5, X stars or Y kills to go"). Stars are an in-match resource only (never a currency; ADR-0271), and no star-spending item exists yet; any in-match sink is a later decision. Weapons are ordered by difficulty with a documented TTK table; demo content is split from production.
