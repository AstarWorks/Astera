# Area: modes, combat, weapons

Owner track `wp/modes-combat`. Seed: audit 2026-10-26. Items: Board prefix `MODE-`.

## 構想 (source)
- Siege PvP with gun / sword / magic roles, 15-30 min matches (`docs/game-design/vision.md`, `pillars.md`).
- **Norma is part of every mode** (founder 2026-10-26, ADR-0268: shared layer `content/norma-layer/layer.yaml`, the old `norma` mode is now `skirmish`): stars pop from generators, a kill bursts carried stars, per-level STAR or KILL goal, 100% Orange Juice style; Norma levels unlock weapon rarities (ADR-0289), never end a match (ADR-0288, ADR-0271, `docs/game-design/stars-and-norma.md`).
- Weapons RTM-style MAIN+SUB caps; the 2-weapon cap is kept; starter kit includes a gun.
- Matches target siege-scale maps; keep a small debug arena for e2e.
- Playable loop: queue, form, countdown, ACTIVE, fight, respawn, objective, end summary + rewards, lobby (`docs/game-design/playable-loop-checklist.md`).

## 現状
- 6 mode files in `content/game-modes/` (annihilation, carry-tnt, carry-mini-tnt, capture-wool, steal-jewelry, pve-waves); 6 queue lanes in `content/matchmaking/queue.yaml`, one per mode (`carry-mini-tnt` got its lane in MODE-05; the Play menu and lobby pads list the pvp lanes from this file, so no code change). `ShippedMatchContentDecodesTest` fails if a mode has no lane.
- Play gate mode picker with "vs bots" tile per lane (ADR-0248). Bots: A* pathing, star/generator objectives, retreat, Norma goal choice (`tools/bot-runner`).
- Leaving a running match (MODE-14): a dropped connection holds the seat for a 60 s rejoin window, then forfeits; a deliberate leave (`/astera travel lobby`, F-menu Leave) forfeits at once (stars burst, seat released, inventory + lobby kit restored, loss recorded). carry-mini-tnt is a real objective (CarryMiniTntGameMode, MODE-05) built on the RTM concept "collect 10 mini-TNTs into 1 larger TNT" (`docs/adr/0029-rtm-empirical-catalog.md:80`): pieces from the pickup spots (carry up to 4) are banked at the team's OWN base into a pool; at `minis_per_tnt` (10) they combine into one real TNT at `tnt-spawn` (presentation moment `mini-tnt-combined`, pool progress on the sidebar), which only that team can pick up and which wins (`tnts_to_win` 1) when delivered to the enemy base, using the same carry rules as carry-tnt (`TntCarrier`). The own-base banking route and the one-TNT-at-a-time rule are our choices; the docs give only the 10-into-1 idea.
- Real-server playthrough e2e for every mode (`*PlaythroughE2eTest`: norma, annihilation, pve-waves, carry-tnt, carry-mini-tnt, capture-wool, steal-jewelry). The objective-mode ones share `ObjectivePlaythroughBase.finishMatch`, which asserts the end screen, the VICTORY/DEFEAT verdict each player is told and that sound packets reached the client (the client bot records no title packets, so the verdict is read from chat).
- Battle-royale (battle-loyal) and Break Core were removed (2026-10-27); carry-tnt is the default lane. PvE waves is not in the Play picker: it opens from the lobby main-menu PvE tile (`lobby.queue.join` with `lane: pve-waves`).
- ~90 items, 85 skills, ~30 real weapons (guns: pistol, rifle, shotgun, sigil-rifle, vendetta-rifle; swords; 5 staves); demo items (`rtm-blaster`, `simple-shoot`, `vfx-demo-*`, `anim-demo-*`) live in production content.
- Demo/dev items are flagged `astera:demo: "true"` (ADR-0270) and stay usable by id but out of admin catalogs, kits and racks (`DemoContentHiddenScenarioTest`); they were deliberately not moved to a separate content path because game-sim/VFX scenarios load them by id from `content/`. The TTK table is `docs/game-design/weapons/ttk.md` (generated by `scripts/ttk-table.py`, bands guarded by `ShippedWeaponTtkBandsTest`).
- `weapon_limits: "gun:1,sword:1,staff:1,total:2"` enforced by `MatchWeaponLimitListener`, now a default of the Norma layer (`content/norma-layer/layer.yaml`) so every mode keeps the 2-weapon cap (a mode may override or blank it). Covered by game-sim `WeaponLimitScenarioTest` (skirmish + carry-tnt).
- "How Norma wins the match" is told in-game (w4): a chat briefing when the match turns ACTIVE (`MatchBriefingListener`: the mode's objective line `astera.match.briefing.mode.<mode>`, "first to Lv 5 wins", the time-limit ranking); the sidebar clock shows the limit (`3:12 / 20:00`) and the Norma line shows the best rival level (`Lv 2/5 (rival 3)`); the result screen names what decided the match per mode (`summary.reason.objective-by.<mode>`) and prints each team's final Norma standing (`Lv / stars / kills`, snapshotted by `NormaLevelService.clear` before the data is dropped). Game-sim `NormaExplainedScenarioTest`; not yet run in CI (manager's batch).
- The Norma sidebar goal (`Norma Lv n/5`, `Goal: Stars|Kills x/y`) is live for all modes; `NormaPlaythroughE2eTest` now asserts both lines.
- Norma/stars (2026-10-27 economy): star goals 10/30/60/100 (top level ~100), generators 5 stars per 20 s, a death fountains half the carried stack as up to 16 glowing items with gold-dust/firework/END_ROD layers and the `star/burst-boom` cue (pace math: `docs/game-design/stars-and-norma.md`). Generators pop stars, kill bursts stars, level via STAR or KILL goal, `PaperNormaPresentation`; stars cannot yet be spent (items/ultimates not built).
- Field tools + breakable cover (ADR-0090, track tools-blocks): every match participant is lent `field-pickaxe` / `field-axe` / `field-shovel` (iron tier, list `match_tools` in `content/balance/starter-grant.yaml`, delivered by `MatchLoanerKit`; removed at match end). Left-click on a cover block with a tool calls `HitCustomBlockUseCase` (6-tick cooldown): the right tool does 100 per swing, the wrong one 25 or nothing, a vanilla dig on cover is cancelled; crack stages go out via `IBlockBreakAnimationGateway` (`sendBlockDamage`) and per-tool break sounds play. Cover blocks `reinforced-wall` (stone 400 HP, pickaxe), `barricade` (wood 300, axe), `sandbags` (soil 200, shovel), `hardened-soil` (500, pickaxe) are placed in all siege-isles variants via `content/structures/cover-*.yaml`; they are recognised by their unique base material (`resolveByBaseMaterial`). Game-sim `CustomBlockToolScenarioTest`. Not yet: a shop route for tools, drops, player-placeable blocks, an e2e walk.
- Cover damage v2 (ADR-0280, track blocks-v2): skills reach cover only through `block_damage` (flat HP chip, or a tool-matrix hit with `tool`) and `block_place` in skill YAML, all through `CoverBlockService`; guns/spells opted in with small chips (pistol 12, rifle 20, shotgun 30, flame-burst 35, frost-nova 20, lightning-bolt 25, frost-shard 10), skills without the field do nothing. The field tools got right-click skills: pickaxe Breach Strike (300 in radius 2, 8 s), axe Cleave (300 along 6 blocks, 6 s), shovel Dig In (temporary 3x2 sandbag wall, 20 s). Broken cover is not regenerated in a match and is rebuilt at match end (`RestoreBlocksOnMatchEndedUseCase`). Game-sim `SkillCoverDamageScenarioTest`; not yet run by the manager batch. Open: `BlockRecoveryScheduler` still pseudo-heals damaged blocks (+5 HP / 10 s).
- Combat: resource pools, melee, mob damage, 15 statuses, element matrix.
- Stage allocation (MODE-06): a stage id is one fixed set of coordinates in the `arenas` world and hosts one match at a time (`MatchFoundUseCase.isStageBusy`). World slots / `ArenaPaster` (ADR-0255) are design only, with no code yet, so instancing does not exist. Each siege-family lane therefore has its own copy of the stage: `siege-isles` (break-core) and `siege-isles-{tnt,wool,jewelry,loyal,mini-tnt}`, each shifted +800 on z (stages 800 apart, the ADR-0255 region-independence distance), with their own star generators `siege-<variant>-{north,south,center-east,center-west}`. The six siege lanes now run concurrently. When ADR-0255 slots land, delete the variants and point the lanes back at `siege-isles`. Costs: six large stages to build at boot and in the arena marker; keep the copies in sync when editing `siege-isles.yaml`.

## 理想形
Play shows Norma-based modes and PvE first; siege variants sit in an "advanced" group until each has a real-server playthrough. Every mode carries the Norma layer. A newcomer gets gun, sword and staff access in the first match within the 2-weapon cap, and the sidebar always shows the goal ("Lv n/5, X stars or Y kills to go"). Stars are an in-match resource only (never a currency; ADR-0271), and no star-spending item exists yet; any in-match sink is a later decision. Weapons are ordered by difficulty with a documented TTK table; demo content is split from production.
