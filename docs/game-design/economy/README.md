# Economy

通貨 / ガチャ / サブスク / バトルパス。Phase 4〜5 で内容拡充。

## 通貨の役割（ADR-0199）

| 通貨 | 役割 | 入手 | 使い道 |
|---|---|---|---|
| STAR | 日常通貨 | 全マッチ（参加 10 / 勝利 100〜150 / キル 5 …、`content/balance/match-rewards.yaml`）、初回付与 150 | ショップの標準武器（100〜320） |
| GOLD | 希少・上位通貨 | クエスト / 実績 / 勝利時に少量 | ショップの最上位武器（120〜150）、マーケットプレイス |
| GEM | プレミアム | プレイでは得られない | 装飾・利便性（予定） |

**XP は STAR に換算しない**（ADR-0235）。STAR の入手元は上表（マッチ報酬テーブル・初回付与）とミッション／クエスト／実績の通貨報酬・ログインボーナスのみ。ロビーの訓練ダミー・ロビーでの殴り合い・ロビーの MOB 討伐は XP・STAR・ミッション・クエスト・実績・統計・キルフィードのどれも動かさない（マッチ中の PvP だけが数える）。

ループ: マッチ → STAR（+GOLD）→ ショップで武器（アンロック）→ インベントリ／ヴォルト → マッチ（持ち込み = 入場時のインベントリ、ADR-0203）。
目安: 1 マッチで STAR 30〜200、標準武器は 2〜6 マッチ分。

## ショップ GUI

アイコン = アイテム本体（名前・ロア・性能）+ 価格（購入通貨で表示、不足は赤で不足額）+ 在庫 + クリック案内。
100 以上の価格は 2 回クリックで確定。下段にウォレット（STAR / GOLD / GEM）。

## 所有・購入履歴・ヴォルト（ADR-0211）

- 武器は**アンロック**: 一度買えば永久に自分のもの（`limit: once`）。ロストしても無料で再受け取り（所持中は不可）。消耗品は `limit: unlimited` で毎回課金。
- ショップは 1 ページ 45 件、カテゴリ切替、購入履歴ボタン（直近 45 件）。売り戻し（sell-back）は無し — アンロックには売る実体が無い。
- ヴォルトは 3 ページ × 45 スロット + ページ送り・整理ボタン。ショップ・ヴォルトともマッチ中は利用不可。
- ホットバー: ロビーのメニューキットは右端 5..8、武器は左 0..4。
