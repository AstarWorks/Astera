# Economy

通貨 / ガチャ / サブスク / バトルパス。Phase 4〜5 で内容拡充。

## 通貨の役割（ADR-0199）

| 通貨 | 役割 | 入手 | 使い道 |
|---|---|---|---|
| STAR | 日常通貨 | 全マッチ（参加 10 / 勝利 100〜150 / キル 5 …、`content/balance/match-rewards.yaml`）、初回付与 150 | ショップの標準武器（100〜320） |
| GOLD | 希少・上位通貨 | クエスト / 実績 / 勝利時に少量 | ショップの最上位武器（120〜150）、マーケットプレイス |
| GEM | プレミアム | プレイでは得られない | 装飾・利便性（予定） |

ループ: マッチ → STAR（+GOLD）→ ショップで武器 → ロードアウト → マッチ。
目安: 1 マッチで STAR 30〜200、標準武器は 2〜6 マッチ分。

## ショップ GUI

アイコン = アイテム本体（名前・ロア・性能）+ 価格（購入通貨で表示、不足は赤で不足額）+ 在庫 + クリック案内。
100 以上の価格は 2 回クリックで確定。下段にウォレット（STAR / GOLD / GEM）。
